# ディストリビューター比較

## 比較軸

| 項目 | 意味 |
|---|---|
| 料金 | 初期費用・月額・年額・リリース単位 |
| 還元率 | ストリーミング/販売収益のアーティスト還元 |
| 配信先 | Spotify / Apple Music / Amazon Music / TikTok / Instagram 等 |
| SNS連携 | TikTok・Instagram・YouTube・CapCut等 |
| プロモーション | プレイリスト、Discovery Mode、キャンペーン等 |
| アーティスト数 | 1人運用か複数アーティスト/レーベル運用か |
| スプリット | 共同制作者への収益分配 |
| レポート | 再生数・収益・オーディエンス分析 |
| 権利管理 | 著作権・Content ID・近接権等の対応 |
| MV/カラオケ | 音源以外の展開 |
| 国内対応 | 日本語サポート、国内ストア、国内向け機能 |
| 配信速度 | 審査から配信開始までの目安 |

## 初期比較

### SoundOn

TikTokとの親和性を最重要視するなら有力。Liteは初期費用・月額0ドルで、ストリーミング収益の90%還元。Core/Maxでは100%還元を掲げる。TikTok、CapCut、プロモーション分析、収益スプリットなどが特徴。

### TuneCore Japan

日本での個人アーティスト運用を比較しやすい定番候補。55以上のストアへ一括配信し、配信収益100%還元。年間4,400円からのUnlimited、またはシングル1,551円/年などのPay Per Releaseがある。著作権管理、YouTube収益化、MV、カラオケ、スプリットなど周辺機能も広い。

## 更新ルール

- 価格は税込/税別を明記する
- 無料プランは「0円」だけでなく還元率も記録する
- 「収益100%」は配信ストア側の手数料まで含む意味ではない場合があるため注記する
- 公式料金ページを一次情報とする
- `source_checked` を更新日として保存する
- 比較対象を増やすときは、同じ項目を埋めてから追加する
