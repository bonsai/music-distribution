# 7社徹底比較

対象: SoundOn / TuneCore Japan / DistroKid / CD Baby / RouteNote / BIG UP! / LANDR

## 比較軸

| 軸 | 意味 |
|---|---|
| 料金モデル | 無料、年額、リリース単位、更新料 |
| 還元 | アーティスト受取率。gross/netの基準も保持 |
| 配信規模 | ストア数・地域 |
| SNS | TikTok / Instagram / YouTube / CapCut等 |
| プロモーション | プレイリスト、Discovery Mode、pitching等 |
| アーティスト数 | ソロ / 複数 / レーベル |
| Split | 共同制作者への収益分配 |
| Analytics | 再生・収益・オーディエンス分析 |
| 権利 | マスター、著作権管理、Content ID等 |
| MV / Karaoke | 音源以外の展開 |
| 国内対応 | 日本語、国内ストア、国内サービス |
| 配信速度 | 最短日数が明記されている場合のみ記録 |
| 解約後 | カタログ維持と手数料条件 |

## 会社ごとのポジション

- **SoundOn**: TikTok / CapCutを中心にショート動画発見を強くしたいケース。
- **TuneCore Japan**: 日本向け機能、55+ストア、著作権・YouTube・カラオケ等まで一体で扱いたいケース。
- **DistroKid**: 年額固定で大量リリースするケース。
- **CD Baby**: 年額サブスクリプションを避け、リリース単位で払いたいケース。
- **RouteNote**: 無料モデルで開始し、伸びたリリースだけPremiumへ移すケース。
- **BIG UP!**: 日本向けの低価格・無料モデルを試したいケース。
- **LANDR**: 配信に加えてマスタリング、プロモーション、分析など制作ワークフローもまとめたいケース。

## Evidence policy

料金・還元率・機能は変動するため、一次情報を必須とする。各事実は `data/evidence.json` の `evidence_id` に紐付け、URLと確認日を保存する。

比較の結論は「最強の1社」ではなく、質問の制約に対する適合度として計算する。

## 注意

「100%還元」は消費者が支払った総額の100%という意味ではない。各社が何を受領額の母数としているかを別フィールドで保持する。またマスター音源の配信ロイヤリティと作詞作曲の出版権収入を混同しない。
