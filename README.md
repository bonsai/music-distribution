# music-distribution

音楽配信ディストリビューター比較・リリース管理のためのデータベース。

## 目的

「どこから配信するか」を感覚ではなく、料金・還元率・配信先・TikTok/YouTube等の強み・複数アーティスト対応などで比較できるようにする。

基本モデル：

`作品 → 音源 → アートワーク → メタデータ → ディストリビューター → 配信ストア → 公開状態 → 収益`

## データ

- `data/distributors.json` — ディストリビューター比較データ
- `docs/distributors.md` — 比較項目と調査方針

## 方針

料金・還元率など変動する情報は、公式サイトを一次情報として更新日とURLを記録する。
